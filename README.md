# AutoEdit downloads

AutoEdit applies an editing style to photos in Lightroom Classic.
This repository only holds the installers and updates; there is no source code here.

**Install:** open the [latest release](https://github.com/mattpjclark/autoedit-releases/releases/latest),
download `AutoEdit-Setup-<version>.zip`, unzip it and double-click `Install AutoEdit.cmd`.
Read `Read me first.txt` inside the zip for details.

**Update:** installed copies of AutoEdit check this repository by themselves and offer new
versions in the app (sidebar button, or Settings > Updates).

Styles are not published here; they are shared separately as `.autoedit` files.
